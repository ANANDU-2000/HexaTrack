# Dashboard Wireframe

## Section Order
1. Header with WorkspaceSwitcher
2. Summary strip
3. One trend chart
4. Category breakdown
5. Recent transactions up to 5
6. One AI insight

## Sticky Areas
- Bottom navigation fixed.
- Add Transaction action thumb reachable.

## Spacing Hierarchy
- 24px page padding.
- 24px section gap.
- Cards use 24px radius.

## Scroll Rules
- Keep the primary job within two mobile screens.
- Move advanced details to secondary screens or progressive disclosure.

## Forbidden
- No extra graphs above fold.
- No long widget feed.
- No decorative cards.
