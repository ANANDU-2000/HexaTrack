# History Wireframe

## Section Order
1. Header
2. Sticky search
3. Filter chips max 3 visible
4. Date-grouped transaction list
5. Pagination/load more

## Sticky Areas
- Search can stay near top while scrolling.
- Bottom nav fixed.

## Spacing Hierarchy
- Rows minimum 72px.
- Group headers compact.

## Scroll Rules
- Keep the primary job within two mobile screens.
- Move advanced details to secondary screens or progressive disclosure.

## Forbidden
- No horizontal tables.
- No nested filters.
- No more than 3 visible filters by default.
