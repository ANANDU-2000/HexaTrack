# HexaTrack Read First

This is the AI and developer entry point. It prevents documentation overload.

**Onboarding / infra / Cursor hub:** [START_HERE_MASTER.md](START_HERE_MASTER.md)

## Always Read

1. [BUILD_ORDER.md](BUILD_ORDER.md) — **canonical delivery sequence** for auth/admin and major verticals.
2. [BUILD_TO_FINISH_HEXATRACK.md](BUILD_TO_FINISH_HEXATRACK.md)
3. [CURRENT_TASK.md](CURRENT_TASK.md)
4. Relevant feature file in [../features](../features)

- Workspace work: read [../features/feature-02-workspaces.md](../features/feature-02-workspaces.md) and [WORKSPACE_PERMISSIONS.md](WORKSPACE_PERMISSIONS.md).
- AI work: read [AI_SYSTEM_RULES.md](AI_SYSTEM_RULES.md), [API_KEY_MANAGEMENT.md](API_KEY_MANAGEMENT.md), and [MICROCOPY_GUIDE.md](MICROCOPY_GUIDE.md).
