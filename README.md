# HexaTrack

HexaTrack is a premium, mobile-first finance workspace platform for founders, freelancers, business owners, and serious personal finance users.

It is not an accounting suite, ERP, crypto dashboard, or generic AI-generated dashboard. The product must stay calm, fast, minimal, trustworthy, and finance-safe.

## Stack

- Frontend: Next.js 15, TypeScript, Tailwind CSS, Zustand, Framer Motion, Lucide React, Zod
- Backend: ASP.NET Core, Entity Framework Core, Npgsql, Hangfire, Redis, JWT
- Database: PostgreSQL on Render
- Hosting: Vercel frontend, Render backend
